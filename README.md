# Nimra Fatima — Portfolio

Live site: https://nimra71.github.io/-nimra-fatima-portfolio/

A personal portfolio built entirely from scratch — no template, no framework — as a single, self-contained HTML file with custom animations, a 3D project carousel, and a built-in assistant visitors can chat with.

## Features

- Percentage-counter loading intro with an iris-wipe reveal
- Custom cursor that reacts to hover state
- Letter-by-letter, blur-in headline reveal
- Magnetic buttons and cursor-tracked spotlight glow
- 3D tilt on project cards, with an auto-advancing carousel
- Animated count-up stats
- Scrolling skills ticker and scroll-progress bar
- Subtle film-grain texture overlay
- Fully responsive, with a dedicated mobile navigation menu
- Built-in chat assistant that answers visitor questions about my background

## Tech Stack

Vanilla HTML, CSS, and JavaScript — no build step, no dependencies. Fonts via Google Fonts (Fraunces, Inter, JetBrains Mono).

## Running Locally

Clone the repo and open `index.html` directly in a browser — no server or build process required.

```bash
git clone https://github.com/Nimra71/-nimra-fatima-portfolio.git
cd -nimra-fatima-portfolio
open index.html
```

## Deployment

Hosted for free on GitHub Pages, served directly from `index.html` at the repository root.
